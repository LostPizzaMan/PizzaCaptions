# Contributing

Pull requests are welcome!

By submitting a pull request, you confirm that you wrote the contribution
yourself and have the right to submit it, and you agree that the maintainer
may use, modify, distribute, and re-license your contribution as part of the
project.

Forking this repository on GitHub to open a pull request is permitted under
the project [LICENSE](LICENSE).

A few practical notes:

- Keep PRs focused: one fix or feature per PR.
- For larger changes, please open an issue first so we can discuss.
